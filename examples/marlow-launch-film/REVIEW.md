## The question: is it Lumen's film with another product in it?

It was made with the same recipe and compiler and no new recipe. What it shares with the Lumen film is the
product-as-live-page and one long take. What it does not share:

|                           | Lumen                                           | Marlow                                                               |
| ------------------------- | ----------------------------------------------- | -------------------------------------------------------------------- |
| Structure                 | The old way, a cut, the product, the brand      | A user's six minutes after a meeting, start to finish, no cut        |
| Where the problem is told | A headline and a second interface               | In the product's own content: the transcript's last lines            |
| Composition               | A page: serif headline and product trade places | The product fills the frame; words run in a band beneath it          |
| Type                      | Playfair Display at two scales, five placements | Outfit, one size, one place, like subtitles                          |
| Camera                    | Pushes in and reframes on a stone stage         | Travels across the page: down the transcript, across, down the notes |
| How the product enters    | Through one element that opens                  | It is there at frame 0                                               |
| Ending                    | The interface closes down to its mark           | The camera pulls back and leans; the name is set in type             |

## What this test does and does not show

It shows the system can express a second direction without new recipes: the differences above were all
written in the plan. It does not show the quality holds for a real product: both interfaces were written by
the same hand as the films, to suit them. That test needs a product that was not.
